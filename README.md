# Shouryan Sood — Personal Portfolio

Premium, recruiter-facing portfolio built with React + Vite.

## Design
- Dual palette: warm editorial light / near-black dark
- One emphasis colour: acid-lime
- Responsive, minimal, typography-led
- No stock imagery; the content and work are the visual focus

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy with GitHub Pages

Push the `main` branch to GitHub and enable **Settings → Pages → GitHub Actions**.
The workflow in `.github/workflows/deploy.yml` builds the Vite app and deploys it automatically.

## Before publishing
Replace the placeholder LinkedIn, GitHub and email links in `src/main.jsx`.
Add your final resume PDF if desired.
